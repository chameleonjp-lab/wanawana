# M8 表示領域の変更と入力の境界

戦闘中に画面回転、ブラウザの表示領域変更、分割表示、端末のサイズ変更が起きたら、まず入力を中立へ戻して試合を停止する。`pointercancel` または `lostpointercapture` が起きた場合も、入力を消すだけでなく、戦闘中は同じ停止境界として扱う。

戦闘画面を開いた直後のレイアウト確定は停止理由にせず、戦闘開始・再開後に確定した表示領域を基準として記録する。基準と異なる変更だけを試合中の表示領域変更として扱う。指の役割や、変更前の操作部の座標を持ち越さない。停止中は固定tickを進めず、再開ボタンを押した後の新しい入力だけを受け付ける。

変更の検知には、通常の画面サイズ変更、表示領域の変更、盤面要素そのものの大きさ変更を使う。サイズが落ち着いた次の描画で、盤面とHUDを一度だけ描き直す。PixiJSの描画解像度変更と、入力側の `getBoundingClientRect()` の再取得を分け、古い座標を再利用しない。

`pointercancel` と `lostpointercapture` はサイズ変更と同じ中断境界として扱う。該当する指だけでなく、受理前の射撃・罠設置・調査とキーボードの押下状態をすべて破棄し、再開後の新しい入力まで操作を中立にする。ブラウザが指を取り上げた後に、離す前の命令が次のtickへ遅れて届かないことを保証する。

タイトル画面では停止せず、戦闘中だけ停止する。停止中や結果画面では必要な描画だけを更新し、保存された中断試合の内容や再現用ハッシュを変更しない。

受入条件は、サイズ変更中にtickが増えないこと、押しっぱなしの移動・射撃・設置・調査が残らないこと、`pointercancel` とcapture喪失後にも受理前命令が残らないこと、再開後に新しい押下から操作できること、同じseedと入力列の状態ハッシュが通常表示と一致することである。
