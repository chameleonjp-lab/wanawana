# M7 CPU罠設置の安全境界

CPUの罠設置は、相手の現在セルに近い候補から固定順で調べる。ただし、壁セル、CPU自身の罠、CPUへ共有済みの敵罠へは設置しない。

## 候補の広げ方

最初は相手の上下左右4セルを調べる。交差路のように4方向が壁・既存罠・相手との重なりで使えない場合は、距離2、距離3の順に同じ固定順で候補を広げる。候補がないtickでは、CPUは設置命令を出さず通常の移動・射撃へ戻る。

候補セルと向きの決定は、面ID、現在位置、相手位置、CPUが見えている罠だけから行う。ブラウザ時刻・乱数・未発見罠の座標は使わない。

## 公平性

- 未発見の敵罠は、候補セルの除外条件へ入れない。
- 共有危険表示が出た場合は、既存の難度別反応tickで調査を開始する。
- 難度によって変えるのは反応、射撃、連鎖計画だけで、壁判定・設置コスト・罠効果は変えない。
- 設置候補の改善はCPUの命令選択だけに限定し、固定tickの世界計算、勝敗、リプレイ形式、状態ハッシュの規則は変更しない。

## 受入検査

- 交差路の中央4方向が壁でも、CPUが合法な距離2以遠のセルを選べる。
- 共有済みの敵罠を候補から外す。
- 未発見の敵罠を見ないまま、同じ候補を選ぶ。
- 同じseed、面、入力、難度で同じ設置命令と最終ハッシュになる。
