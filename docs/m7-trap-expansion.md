# M7 罠拡張（ポン玉・モヤびん）

M7の1.0内容として、既存の3罠へ2つの役割を追加する。

## ポン玉

- 設置コストは歯車2。
- 接触したtickにはダメージを与えず、45tick（0.75秒）の導火線へ入る。
- 導火線中は同じ罠を再発動しない。導火線が終わると罠の中心から1.4マス以内へ20ダメージと0.6マスの押し出しを行う。
- 接触時点の連鎖ID、親イベント、責任者を整数で保存し、爆発イベントへ引き継ぐ。CPUや再現再生で推測し直さない。
- 導火線が始まった後は、そのポン玉を調査・解除できない。接触後は、導火表示を見て爆発範囲から離れる。
- 爆発イベントが発生したとき、中心から1.4マス以内にある未発動のポン玉を、同じ連鎖ID・責任者で新たな45tickの導火線へ入れる。候補は罠IDの昇順で扱い、すでに導火線へ入ったポン玉は上書きしない。
- 爆発範囲にプレイヤーがいない場合も、近いプレイヤーを記録上の対象として0ダメージの爆発イベントを残し、近くのポン玉へ連鎖できる。距離が同じ場合はプレイヤーID 0を先にする。

## モヤびん

- 設置コストは歯車1。
- 接触時に一度だけ発動し、210tick（3.5秒）だけ罠の中心から1.5マス以内をガス範囲とする。
- ガス範囲が発生した後は、そのモヤびんを調査・解除できない。範囲外へ移動して効果を避ける。
- ガス範囲内の移動速度を1tickあたり512単位から358単位へ固定的に落とす。範囲外へ出た次tickから通常速度へ戻る。
- ダメージや押し出しは行わず、発動イベントだけを結果記録へ残す。

## ポン玉からの誘爆

- ポン玉の爆発中心から1.4マス以内にある、導火線中でない非ポン玉罠を罠IDの昇順で調べる。
- その罠の接触範囲へプレイヤーがいる場合だけ、爆発と同じtickに1回だけ発動する。対象がいない罠は残り、遠隔でダメージを与えない。
- 発動イベントはポン玉の爆発イベントを親にし、同じ連鎖ID、連鎖長を1段増やした値、同じ責任者を保存する。
- 爆発または誘爆で押し出しが起きた場合、その移動線分上の罠を通常の接触判定と同じ規則で続けて調べる。候補は発生順、接触距離、罠IDで固定し、同じtickでも親イベントを1つずつつなぐ。
- 押し出し床とビリビリ盤は次の罠へ同tickで進み、落とし穴とモヤびんは移動を生まないため、そこで伝播を終える。線分上でポン玉へ接触した場合は、接触イベントを記録せずに導火線へ入り、45tick後の爆発へ文脈を引き継ぐ。
- 連鎖長8、1tickのイベント128件を超える状態は正常な試合として続けず、技術的無効へ移す。上限到達時にイベントを黙って捨てない。

## 実装境界

今回の差分は、固定tickのシミュレーション、決定論ハッシュ、CPUの罠選択、罠札UI、Pixi表示、音、結果ラベル、ハネ板固定のロードアウト、端末内戦績、ポン玉同士の遅延連鎖、ポン玉からの同tick連鎖伝播と検査を揃える。3面の開始位置・テーマ・ハッシュ・壁衝突は `docs/m7-maps.md` の作業単位で追加済み。対戦記録は、結果画面から受理済み命令と状態ハッシュを含むJSONをコピーできる。アカウント同期やランキングは扱わない。
