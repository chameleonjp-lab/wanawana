# M5 初回操作練習

タイトル画面の「操作を練習する」から、固定tickの練習舞台へ入れる。練習は本戦とは別の一時状態で、端末内戦績・中断記録・対戦記録を作らない。

## 4段階

1. 移動して誘導弾を1発撃つ
2. 罠札を押し、足元の予告を確認して設置する
3. 練習用に表示されたハネ板からビリビリ盤へ押し出し、2段連鎖を起こす
4. 黄色い危険表示の近くで、敵のパカット床を調査して解除する

各段階は、画面が実際に受理した移動、射撃、設置、連鎖、解除のカウンターから判定する。説明文の読了やボタンの押下だけでは合格にならない。段階ごとに15秒相当進まない場合は短いヒントを表示する。

練習用の連鎖と敵罠は、前段階を終えた後にだけ追加する。見えない罠の位置を設置失敗から推測できないよう、本戦の設置ルールは変更しない。練習完了後は同じ画面からCPU戦へ移れる。

## 合格条件

- 4段階が固定tickの進行だけで再現できる。
- 練習の入力や配置が本戦のリプレイ、端末内戦績、中断保存へ入らない。
- 「練習をやめる」でタイトルへ戻り、次の本戦を通常設定から開始できる。
- 練習完了は専用の `wanawana:v1:tutorial` キーだけへ保存し、保存拒否時も練習自体は完了できる。
- 動きを減らす設定、音なし、画面回転・フォーカス喪失時の既存中断境界を練習にも適用する。

本実装は自動実演の代わりに、15秒後のヒントと練習用の固定配置を使う。初見試遊で60〜90秒以内に4段階を口頭補助なしで終えられるかをM5の実機確認で測る。
