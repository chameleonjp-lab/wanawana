# M8 WebGL描画喪失からの復旧

PixiJSのWebGL描画領域を失ったとき、戦闘規則の時計を進めず、入力と音を止める。復旧しただけでは試合へ戻らず、利用者が「再開する」を押した後にだけ固定tickを再開する。

起動時はWebGLを優先し、WebGLを開始できない場合はPixiJSのCanvas描画へ切り替える。Canvas描画ではWebGL描画領域の喪失を監視しない。WebGLとCanvasのどちらも開始できない場合だけ、対応外画面を表示する。

WebGLまたはCanvasの準備中に画面非表示、フォーカス喪失、ページ移動、回転が起きた場合は、進行中の非同期開始処理を無効にする。古い開始処理が停止後に試合を始めたり、保存試合の再開処理と二重に動いたりしない。

## 状態の境界

- `webglcontextlost` を受けたら `preventDefault()` を呼び、現在の試合を一時停止する。
- 5秒以内に `webglcontextrestored` を受け、既知の画面を一度描けた場合だけ再開ボタンを有効にする。
- 同じ試合で2回目の描画喪失、または5秒以内に描画を確認できない場合は、その試合を技術的に無効としてタイトルへ戻る。
- 無効になった試合は勝敗と端末内戦績へ保存しない。通常の結果画面へ渡さない。
- 新しい試合を開始すると喪失回数を0へ戻す。

PixiJS側のGPU資源再生成を待ってから、舞台を再描画する。復旧中にタップ、長押し、キーボード、音の再生を再開しない。自動再開は行わない。

`tests/core/context-recovery.test.ts` は、試合外の喪失を無視すること、復旧後の明示的な再開、2回目の喪失による無効化、タイトル遷移による状態消去を検査する。
