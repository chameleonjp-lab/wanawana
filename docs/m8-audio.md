# M8 音声の停止と失敗時の境界

音は試合の時計、攻撃、罠、勝敗を決めない。`AudioContext` はアプリ内で一つだけ使い、開始または再開の利用者操作の中で再生を試す。

## 画面への伝え方

- 音が動いているときは「音: オン」と表示する。
- 利用者が切ったときは「音: オフ」と表示する。
- ブラウザが音を中断したときは「音: 中断中」と表示し、試合は止めない。
- 音声機能が使えない、または閉じられたときは「音: 利用不可」と表示し、音なしで試合を続ける。

画面非表示、ページ移動、停止、WebGL喪失では再生中の音源を停止し、音声を一時停止する。画面へ戻っただけでは鳴らさず、利用者が再開を押した場合だけ再生を試す。停止中に予約された古い効果音は復帰後へ持ち越さない。同時再生数は8音までとする。

`tests/audio/sound.test.ts` では、音声状態の分類が固定され、描画時刻や固定tickを参照しないことを確認する。ブラウザが音声を拒否する実機確認は、公開前の受入項目として別に記録する。
