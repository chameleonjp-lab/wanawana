## PR01の実装・検査結果（2026-09-08）

- 移動、弾の押し、ハネ板、衝撃の押し、爆風の押しを、人物半径を含む線分掃引の衝突解決へ統一した。壁の面だけでなく丸い角を扱い、壁の途中で停止し、接線方向の滑りと壁から離れる移動を許可する。
- A02（gearworksで人物が壁を通り抜ける）は、壁セルの手前で停止することを再現検査で確認した。壁角、長い斜め移動、アリーナ端、障害物配列の並び替えも回帰検査に含めた。
- A03（同時爆発のID交換でHPが60/80へ分岐）は、共通の爆発前スナップショットからダメージと押しを収集し、対象ごとに一括適用する処理へ変更した。IDを交換しても両方の爆弾が同じ対象へ20ずつ適用され、HP60になることを確認した。複数方向の押しはベクトル長をハネ板の上限で丸める。
- リプレイを `wanawana-sim-v5`、中断保存を `wanawana-resume-v5` とし、v4の記録を現行物理へ誤って再生しない境界を追加した。新しい保存から60tick進めた状態が中断なしの状態hashと一致することを確認した。
- `npm run check`（型検査、26ファイル130テスト、ビルド）と `npm run verify:dist`（15ファイル、参照リソース13件）が成功した。

## PR02の実装・検査結果（2026-09-11）

- 設置命令に含まれるセルは、入力層が保持した予告セルの確認値としてだけ扱い、コアは常に人物の現在セルを捕捉する。確認値が現在セルと異なる命令、片側だけのセル指定、CPUの遠隔セル指定は設置を開始しない。
- 設置中の人物が外力や復元済み状態によって予告セルを離れた場合は、歯車と罠を消費せず取り消す。設置開始後の0.30秒は移動・射撃を受け付けず、既存の弾命中・罠効果による取り消しも同じ状態を通る。
- 新しい罠はプレイヤー・CPU双方の出現地点から1.5セル以内へ置けない。CPUは遠隔セルを命令せず、合法な足元セルへ移動してから同じ設置命令を出す。壁際の経路改善はPR06へ残す。
- 退場中と復帰保護中を共通の保護判定へ統一した。保護中は入力（移動・射撃・設置・調査）、弾の押し、罠のダメージ・押し・減速を受け付けず、復帰保護の1tickを全効果解決後に消費する。これにより保護終了tickの爆風だけが先に通る境界も防いだ。
- 行動契約の変更に合わせてリプレイ入力版を3、リプレイを `wanawana-sim-v6`、中断保存を `wanawana-resume-v6` へ更新し、PR02以前の記録を理由付きで拒否する。
- PR02固有の6テストを追加し、既存を含む `npm test` は27ファイル136テストで成功した。遠隔設置、セル離脱、出現禁止範囲、復帰中の全入力、退場・復帰中の爆風、ガス減速を直接検査している。
