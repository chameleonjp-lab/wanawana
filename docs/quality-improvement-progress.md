## PR01の実装・検査結果（2026-09-08）

- 移動、弾の押し、ハネ板、衝撃の押し、爆風の押しを、人物半径を含む線分掃引の衝突解決へ統一した。壁の面だけでなく丸い角を扱い、壁の途中で停止し、接線方向の滑りと壁から離れる移動を許可する。
- A02（gearworksで人物が壁を通り抜ける）は、壁セルの手前で停止することを再現検査で確認した。壁角、長い斜め移動、アリーナ端、障害物配列の並び替えも回帰検査に含めた。
- A03（同時爆発のID交換でHPが60/80へ分岐）は、共通の爆発前スナップショットからダメージと押しを収集し、対象ごとに一括適用する処理へ変更した。IDを交換しても両方の爆弾が同じ対象へ20ずつ適用され、HP60になることを確認した。複数方向の押しはベクトル長をハネ板の上限で丸める。
- リプレイを `wanawana-sim-v5`、中断保存を `wanawana-resume-v5` とし、v4の記録を現行物理へ誤って再生しない境界を追加した。新しい保存から60tick進めた状態が中断なしの状態hashと一致することを確認した。
- `npm run check`（型検査、26ファイル130テスト、ビルド）と `npm run verify:dist`（15ファイル、参照リソース13件）が成功した。
