# M8 中断した試合の復帰

Safariの再読込やページ破棄で試合が消える場合に備え、戦闘中の固定更新が120tick（約2秒）に達するたび、現在の世界状態を `wanawana:v1:resume` へ置き換えて保存する。

保存するのはワナワナ専用のキーだけで、指の座標や生の入力履歴は保存しない。保存値には版、調整値、面、疑似乱数方式、CPU難度、tick、世界状態ハッシュを含める。タイトル画面で30分以内の値だけを候補として表示し、利用者が「中断した試合を再開」を押した場合に限って戦闘へ戻る。

## 失敗時の扱い

- 保存の拒否、容量超過、壊れたJSON、未来版、期限切れ、ハッシュ不一致は候補から外す。
- 保存できない端末でも、現在の試合は止めず、その場で遊び続けられる。
- 新しい試合、結果到達、タイトルへ戻る操作では中断記録を削除する。
- 再開した試合は、開始時点からの入力列を持たないため、再現記録のコピー対象にしない。
- `localStorage.clear()` は使わず、他作品の保存値へ触れない。

`src/core/resume.ts` はJSONの大きさ、配列数、整数範囲、世界状態ハッシュ、版、面、調整値、保存時刻を検査する。検査に失敗した値を世界へ渡さないことを、`tests/core/resume.test.ts` で確認する。
