# M5 設計図リザルト

結果画面の「舞台の設計図」は、試合中に表示用としてメモリへ集めた情報だけから描く。ルール計算の正本、リプレイJSON、端末内戦績には追加の履歴を持たせない。

## 表示するもの

- 舞台の9×13セル、通れない壁、舞台テーマ
- 両者が設置した罠のセル、種類、所属、ハネ板の向き
- 結果時点から直近5秒のプレイヤー移動線（黄色）
- 直近36件までの発動番号（白数字）
- `parentEventId` で結ばれた連鎖の因果線（紫）
- 下段の文章一覧にある発動対象、責任者、ダメージ、連鎖段数

罠の履歴は、罠が世界へ現れたtickで記録する。発動と同じtickに消費されて現存一覧へ残らなかった場合は、発動位置をセルへ丸めた最小の設計図印をイベントから補う。再開試合は再開時点で存在する罠を初期値として取り込むが、再開前に消滅した罠の配置線は復元しない。

## 表示の境界

履歴は画面を閉じると破棄し、保存・共有・再現データへ書き出さない。表示の追加・削除・色・アニメーションは、固定tick、当たり判定、入力受付、勝敗、状態hashへ影響させない。連鎖が36件を超えた試合では、設計図を過密にせず、最新36件と下段の全連鎖説明を表示する。

## 確認項目

- 罠がない試合でも舞台と移動線を表示できる。
- 発動順と因果線が、左右の所属色だけに依存せず読める。
- 動きを減らす設定・音なしで、番号と下段の文章から同じ敗因を説明できる。
- 結果からタイトルへ戻り、次の試合で前の設計図が残らない。
