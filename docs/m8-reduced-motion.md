# M8 動きを減らす設定への対応

端末やブラウザで「動きを減らす」が指定されている場合、罠の発動地点を示す輪郭は残し、外側へ広がる輪と放射線だけを表示しない。発動したこと、種類、発動順を確認できる情報は残す。

この切り替えは描画だけに適用する。固定tick、移動、入力の受付、衝突、罠の効果、音声、勝敗、再現用ハッシュは通常表示と同じである。表示側の設定を試合規則へ渡さない。

通常表示では発動から12tickまで短い拡大表現を表示し、30tickで輪郭を消す。「動きを減らす」では拡大表現を出さず、輪郭を36tick残す。これにより、派手な動きを避けながら発動を見落としにくくする。

CSSの画面切り替えにも同じ端末設定を適用する。実機では、設定を有効にした状態で発動、連鎖、結果を確認し、通常表示と最終状態ハッシュが一致することを受入条件にする。
