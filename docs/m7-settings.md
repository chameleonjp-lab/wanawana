# M7 設定保存の境界

タイトル画面で選んだ CPU の難しさ、舞台、罠ロードアウトを、同じ端末の次回起動へ引き継ぐ。保存先は作品固有の `wanawana:v1:settings` だけで、外部送信やアカウント連携は行わない。

保存値は `schemaVersion`、`difficulty`、`mapId`、正規化済みの3罠ロードアウトだけに限定する。JSON が壊れている、未知の版である、未定義の舞台・難度を含む、または重複したロードアウトである場合は、設定全体を既定値へ戻す。部分的な値だけを採用して試合規則を変えない。

ブラウザの保存拒否、容量超過、プライベートブラウズ等で読み書きできない場合も、選択中の値をメモリ上で使って試合を開始できる。タイトルには「保存できない」ことを表示し、利用者が保存されたと誤解しないようにする。`localStorage.clear()` は使わず、ワナワナの既知キー以外へ触れない。

設定の変更は選択直後と試合開始前に保存する。中断試合を再開した場合は、その試合の難度・舞台・ロードアウトを次回の既定選択として保存する。勝敗、再現記録、入力列は設定へ混ぜず、既存の戦績・再現の境界を保つ。

単体検査では、既定値、正規化、往復、壊れた JSON、未来版、未知の値、余分な保存フィールドを確認する。実機では保存拒否を起こし、初期値で開始できることと、別作品を模したキーが残ることを確認する。
