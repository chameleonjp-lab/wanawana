# M0 決定論ストレス検査

`tests/core/determinism-stress.test.ts` は、固定された整数入力を少なくとも 10,000 種類の seed に与え、各 seed の 4 tick を2回ずつ実行する。通常のCIは10,000 seed、定期ワークフローは環境変数で100,000 seedに増やす。

毎 tick、次を検査する。

- 位置、HP、資源、タイマー、罠セル、弾、イベントが整数かつ許容範囲内である
- 罠と弾、イベントのIDが重複しない
- 罠4個、イベントログ50,000件、連鎖8個の上限を越えない
- 状態ハッシュが8桁の固定値で、同じseed・同じ受理命令の2回実行で一致する
- 同じtickに複数の罠へ触れる場合は、移動線分上の最初の接触位置、対象ID、罠IDの順で処理する

この検査はCIの通常テストに含める。seed数を減らす変更や、失敗を無視するための再試行を追加しない。`Determinism long stress` は毎日、日本時間の早朝に100,000 seedで実行し、手動実行もできる。
