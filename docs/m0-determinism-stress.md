# M0 決定論ストレス検査

`tests/core/determinism-stress.test.ts` は、固定された整数入力を 10,000 種類の seed に与え、各 seed の 4 tick を2回ずつ実行する。

毎 tick、次を検査する。

- 位置、HP、資源、タイマー、罠セル、弾、イベントが整数かつ許容範囲内である
- 罠と弾、イベントのIDが重複しない
- 罠4個、イベントログ50,000件、連鎖8個の上限を越えない
- 状態ハッシュが8桁の固定値で、同じseed・同じ受理命令の2回実行で一致する

この検査はCIの通常テストに含める。seed数を減らす変更や、失敗を無視するための再試行を追加しない。長時間の100,000 seed検査はmainまたは定期ジョブへ追加する。
