# 将来計画：オフライン起動と更新

この機能はワナワナ1.0には含めない。1.0ではService Workerを登録せず、オンラインで取得した端末のオフライン起動や、更新版の待機・切り替えを提供しない。短いCPU戦の核と、更新事故のない静的公開を先に完成させる。

将来この機能を追加する場合だけ、次の境界を別の実装計画として再確認する。

- Service Workerのscopeは `/wanawana/` に固定し、ルートscopeや別作品のCache Storageへ触れない。
- cache名は `wanawana-<buildHash>` だけにし、必須ファイルを全件取得できない版は有効化しない。
- 試合中はworkerの切り替えや再読み込みを行わず、タイトルまたは結果画面で利用者が明示的に選んだときだけ切り替える。
- 更新失敗時に現在版を消さず、旧版を維持する。

実装を再開するときは、オフライン再起動、更新待機、必須ファイル欠落時の旧版継続、`/wanawana/` 外の要求、他作品のキャッシュ不変を自動検査してから本番へ入れる。
