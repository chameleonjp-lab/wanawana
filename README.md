# ワナワナ

見えない罠を置き、相手を誘導して連鎖させる1対1のブラウザゲームです。

現在は実装計画のM7「1.0内容」を進めています。タイトルから試合、停止、再開、結果までの画面遷移に加え、3面の決定論的な開始位置・テーマ・ハッシュ・壁衝突、移動パッド、射撃入力、固定tickの誘導弾、押し出し、罠札の予告・取消・設置、ハネ板固定＋追加2種のロードアウト、歯車、調査・解除、罠5種の発動、ポン玉の遅延爆発とポン玉同士の連鎖、モヤびんの範囲減速、ダメージ、退場、連鎖イベント、画面離脱時の中立化を収録しています。CPUも、見えている情報だけを使って移動、射撃、罠設置、調査・解除を行います。CPUの難しさは、反応の間隔、射撃の正確さ、連鎖に使う罠の考え方だけを変えられます。結果画面では勝敗理由、両者の体力、罠の設置・解除数、連鎖の内訳、端末内戦績を確認できます。音は任意で切り替えられ、音が使えない場合も試合は続きます。ポン玉以外の爆発誘発と対戦記録の同期は、次の作業単位です。

## 開発

```sh
npm ci
npm run dev
```

確認には次を使います。

```sh
npm run check
```

GitHub Pages向けの公開先は `/wanawana/` です。1.0では、WebGLを表示できない端末へ対応外の案内を表示します。PixiJSのCanvas描画へ自動切替することは前提にしません。

端末内戦績は `wanawana:v1:summary` に結果確定時だけ保存します。技術的に無効になった試合は戦績へ加えません。保存が拒否された端末でも、メモリ上の集計で試合を続けられます。タイトル画面からワナワナ固有の記録だけを削除できます。
